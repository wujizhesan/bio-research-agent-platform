# mRNA sequence design demonstration

A protein sequence can be converted into a candidate mRNA with codon optimization. The sequence plugin calculates GC content, GC3, CAI, UpA, UpU and homopolymer checks. Translation verification confirms that the optimized mRNA still encodes the requested protein.

These heuristic metrics are quality-control signals, not experimentally calibrated expression predictions. Any sequence recommendation requires human review before laboratory use.
